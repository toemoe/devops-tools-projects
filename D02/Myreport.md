## Part 5. Статическая маршрутизация сети

Запустите пять виртуальных машин (3 рабочие станции (ws11, ws21, ws22) и 2 маршрутизатора (r1, r2))

В настройках виртуальной машины настройте сеть должным образом:
Для r1: Adapter 1 (Internal Network, r1-ws11), Adapter 2 (Internal Network, r1-r2), Adapter 3 (NAT)
Для r2: Adapter 1 (Internal Network, r1-r2), Adapter 2 (Internal Network, r2-ws21-ws22), Adapter 3 (NAT)
Для ws11: Adapter 1 (Internal Network, r1-ws11), Adapter 2 (NAT)
Для ws21, ws22: Adapter 1 (Internal Network, r2-ws21-ws22), Adapter 2 (NAT)

### 5.1. Настройка адресов компьютеров

1. Настроить конфигурации компьютера в etc/netplan/00-installer-config.yaml:
2. Перезапустить сетевую службу через sudo netplan apply.
3. Проверить правильность адреса компьютера с помощью команды ip -4 a.

![настрока адресов r1 r2](Image/5p1.png)
![настрока адресов ws11 ws21 ws22](Image/5p2.png)

Ping ws22 из ws21 и r1 из ws11:

![ping](Image/5p3.png)

### 5.2. Включение переадресации IP

Чтобы включить переадресацию IP: sysctl -w net.ipv4.ip_forward=1. Переадресация не будет работать после перезагрузки системы.

![Включение переадресации IP](Image/5p4sys.png)

Откройте файл /etc/sysctl.conf и раскомментируйте следующую строку: net.ipv4.ip_forward = 1. Переадресация IP-адресов включена постоянно.

![Включение переадресации IP](Image/5p5sys.png)

### 5.3. Конфигурация маршрута по умолчанию

1. Настроить маршрут (шлюз) по умолчанию для рабочих станций. Для этого добавьте routes перед IP маршрутизатора в файле конфигурации.
2. Применить с помощью sudo netplan apply и проверить, сработало ли это с ip r.

![ws](Image/5p6.png)

### 5.4. Добавление статических маршрутов

1. Добавить статические маршруты в r1 и r2 в файле конфигурации.
2. Вызвать ip r, показать таблицы маршрутов на обоих маршрутизаторах.

![ws](Image/5p7.png)

3. Запустить команды ip r list 10.10.0.0/[netmask] и ip r list 0.0.0.0/ 0 на ws11.

![ip r](Image/5p9.png)

Адрес 0.0.0.0/0 - любой адрес, а значит, команда ip r list 0.0.0.0/0 выведет все возможные маршруты, доступные на этом устройстве. Результат команды ip r list 10.10.0.0/18 будет отличаться, так как этот адрес есть в сети устройства, и нет необходимости обращаться к маршрутизатору для дальнейшей передачи пакета.

Ping ws11 -> r2:

![ping](Image/5p8.png)

### 5.5. Составление списка маршрутизаторов

1. Запустить команду дампа tcpdump -tnv -i enp0s3 на r1
2. Использовать утилиту traceroute(tracapath) для составления списка маршрутизаторов по пути ws11 -> ws21

![trace](Image/5p10trace.png)

### 5.6. Использование протокола ICMP при маршрутизации

1. Запустить на r1 сбор сетевого трафика, проходящего через eth0, с помощью tcpdump -n -i enp0s3.
2. Пропинговать несуществующий IP (например, 10.30.0.111) из ws11 с помощьюping -c 1 10.30.0.111 команды.

![icmp](Image/5p11.png)
